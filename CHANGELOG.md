# Changelog

Notable changes to Check Reminder are documented here.

This project follows Semantic Versioning (`MAJOR.MINOR.PATCH`). Dates use ISO format (`YYYY-MM-DD`).

## [2.0.0] - 2026-10-23

### Added
- Authenticated user experience using Supabase.
- Admin panel for user roles and plan management.
- Reusable shadcn-style UI primitives and shared design tokens.
- Responsive, light fintech visual design with Persian typography.

### Changed
- Redesigned authentication, dashboard, cheque cards and forms, notifications, and admin panel.
- Improved mobile layout, focus states, visual hierarchy, and UI consistency.
- Updated documentation and aligned package metadata with the major release.

### Preserved
- Cheque create/read/update/delete workflow.
- Jalali due-date tracking and validation.
- Supabase-backed in-app reminder notifications.

## [1.0.0] - 2026-10-17

### Added
- Initial V1 release for cheque management.
- Dashboard summary, cheque search, and Jalali due-date tracking.
- Supabase-backed in-app notifications.
- Responsive layouts and form validation.
